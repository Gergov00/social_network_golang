# gateway (BFF) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Единственная публичная точка входа: REST/JSON наружу, локальная валидация JWT, реверс-прокси на auth-service для `/auth/*` и gRPC-вызовы в user-service для `/me`, `PATCH /me`, `/users/:handle`.

**Architecture:** Новый модуль `backend/gateway` в том же Go workspace. `/auth/*` уходит нетронутым через `httputil.ReverseProxy` — auth уже говорит REST/JSON и сам ставит httpOnly-cookie, дублировать эту логику незачем. Всё остальное проходит через middleware, который валидирует подпись access-токена локально (HS256, общий `JWT_SECRET`, без похода в auth на каждый запрос) и кладёт `sub` в контекст; хендлеры вызывают user-service по gRPC, используя сгенерированный клиент `userv1.UserServiceClient`, и переводят gRPC-коды в HTTP-статусы. Тесты бьют по трём швам: JWT-мидлварь (чистая логика), хендлеры (подставной `userv1.UserServiceClient` — он интерфейс), прокси (`httptest.Server` вместо реального auth).

**Tech Stack:** stdlib `net/http` + `ServeMux` с методами в паттернах (Go 1.22+), `httputil.ReverseProxy`, `golang-jwt/jwt/v5`, `google.golang.org/grpc`, `ahishka/pkg/gen/ahishka/user/v1`, Uber `fx`, `godotenv`, slog.

## Global Constraints

- **Git в распоряжении Claude**, коммиты — **без** трейлера `Co-Authored-By: Claude`.
- **КРИТИЧНО ДЛЯ БЕЗОПАСНОСТИ:** `id` в gRPC-запросы к user-service для `/me` и `PATCH /me` берётся **только** из провалидированного JWT. Никогда — из тела запроса, query-параметра или заголовка от клиента. Иначе любой авторизованный пользователь сможет читать и править чужой профиль. В `PATCH /me` тело запроса **не должно** содержать поле `id`, а если клиент его прислал — оно игнорируется.
- Версии зависимостей — те же, что уже в проекте: `google.golang.org/grpc v1.83.0`, `google.golang.org/protobuf v1.36.11`, `github.com/golang-jwt/jwt/v5 v5.3.1`, `go.uber.org/fx v1.24.0`, `github.com/joho/godotenv v1.5.1`, `github.com/google/uuid v1.6.0`. Расхождение версий в workspace означает, что сборка берёт одну, а `go.mod` утверждает другое.
- Формат ошибок — как в auth-service: тело `{"error": "<текст>"}`, где текст это `http.StatusText(status)`. Наружу НЕ отдаём `err.Error()` от gRPC/БД.
- Внутри docker-сети адреса — по именам сервисов (`auth-service:10001`, `user-service:50051`), НЕ хост-порты.
- Build context для Dockerfile — **`./backend`**, иначе `go.work` и `ahishka/pkg` не попадут в образ.
- PowerShell не понимает `\` как перенос строки — команды одной строкой.

```go
package config

import (
	"errors"
	"os"
)

type Config struct {
	HTTPPort        string
	JWTSecret       string
	AuthServiceURL  string
	UserServiceAddr string
	LogLevel        string
}

func Load() (*Config, error) {
	cfg := &Config{
		HTTPPort:        getEnv("HTTP_PORT", "8080"),
		JWTSecret:       os.Getenv("JWT_SECRET"),
		AuthServiceURL:  getEnv("AUTH_SERVICE_URL", "http://localhost:10001"),
		UserServiceAddr: getEnv("USER_SERVICE_ADDR", "localhost:50051"),
		LogLevel:        getEnv("LOG_LEVEL", "info"),
	}

	if cfg.JWTSecret == "" {
		return nil, errors.New("JWT_SECRET is required")
	}

	return cfg, nil
}

func getEnv(key, defaultValue string) string {
	value := os.Getenv(key)
	if value == "" {
		return defaultValue
	}
	return value
}
```

```go
import (
	"errors"

const testSecret = "test-secret"

// signToken собирает access-токен той же формы, что выпускает auth-service:
// HS256, идентификатор пользователя в sub.
func signToken(t *testing.T, secret string, sub string, expiresAt time.Time) string {
	t.Helper()

	claims := jwt.RegisteredClaims{
		Subject:   sub,
		Issuer:    "auth-service",
		IssuedAt:  jwt.NewNumericDate(time.Now().Add(-time.Minute)),
		ExpiresAt: jwt.NewNumericDate(expiresAt),
	}
	token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)

	raw, err := token.SignedString([]byte(secret))
	if err != nil {
		t.Fatalf("sign token: %v", err)
	}
	return raw
}

func TestUserIDFromTokenAcceptsValidToken(t *testing.T) {
	want := uuid.New()
	raw := signToken(t, testSecret, want.String(), time.Now().Add(15*time.Minute))

	got, err := NewVerifier(testSecret).UserIDFromToken(raw)
	if err != nil {
		t.Fatalf("UserIDFromToken: %v", err)
	}
	if got != want {
		t.Errorf("id: got %v, want %v", got, want)
	}
}

func TestUserIDFromTokenRejectsExpiredToken(t *testing.T) {
	raw := signToken(t, testSecret, uuid.New().String(), time.Now().Add(-time.Minute))

	_, err := NewVerifier(testSecret).UserIDFromToken(raw)

		t.Errorf("expected ErrInvalidToken for expired token, got %v", err)
	}
}
```

```go
package auth

import (
	"errors"
	"fmt"

	"github.com/golang-jwt/jwt/v5"
	"github.com/google/uuid"
)

// ErrInvalidToken — единая причина отказа для всех случаев: битый токен,
// просроченный, подписанный чужим ключом, с неожиданным алгоритмом или с
// нечитаемым sub. Наружу разница не выдаётся намеренно — она подсказала бы
// атакующему, насколько он близок.
var ErrInvalidToken = errors.New("invalid token")

type Verifier struct {
	secret []byte
}

func NewVerifier(secret string) *Verifier {
	return &Verifier{
		secret: []byte(secret),
	}
}

// UserIDFromToken проверяет подпись и срок локально, без похода в auth-service,
// и возвращает идентификатор пользователя из sub.
func (v *Verifier) UserIDFromToken(raw string) (uuid.UUID, error) {
	token, err := jwt.ParseWithClaims(raw, &jwt.RegisteredClaims{},
		func(token *jwt.Token) (interface{}, error) {
			// Без этой проверки токен с alg=none или с подменённым на
			// асимметричный алгоритмом прошёл бы валидацию.
			if _, ok := token.Method.(*jwt.SigningMethodHMAC); !ok {
				return nil, fmt.Errorf("unexpected signing method: %v", token.Header["alg"])
			}
			return v.secret, nil
		})
	if err != nil || !token.Valid {
		return uuid.Nil, ErrInvalidToken
	}

	claims, ok := token.Claims.(*jwt.RegisteredClaims)
	if !ok {
		return uuid.Nil, ErrInvalidToken
	}

	id, err := uuid.Parse(claims.Subject)
	if err != nil {
		return uuid.Nil, ErrInvalidToken
	}
	return id, nil
}
```

```go
package web

import (
	"context"
	"log/slog"
	"net/http"
	"strings"
	"time"

	"gateway/internal/auth"

	"github.com/google/uuid"
)

type ctxKey int

const (
	loggerKey ctxKey = iota
	userIDKey
)

// statusRecorder запоминает код ответа, чтобы access-лог знал, чем всё кончилось.
type statusRecorder struct {
	http.ResponseWriter
	status int
}

func (r *statusRecorder) WriteHeader(code int) {
	r.status = code
	r.ResponseWriter.WriteHeader(code)
}

func LoggingMiddleware(logger *slog.Logger) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			start := time.Now()

			reqLogger := logger.With("request_id", uuid.NewString())
			ctx := context.WithValue(r.Context(), loggerKey, reqLogger)

			rec := &statusRecorder{ResponseWriter: w, status: http.StatusOK}
			next.ServeHTTP(rec, r.WithContext(ctx))

			reqLogger.Info("request",
				"method", r.Method,
				"path", r.URL.Path,
				"status", rec.status,
				"duration", time.Since(start).String(),
			)
		})
	}
}

func RecoverMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		defer func() {
			if rec := recover(); rec != nil {
				LoggerFrom(r.Context()).Error("panic recovered", "panic", rec)
				WriteError(w, r, http.StatusInternalServerError)
			}
		}()
		next.ServeHTTP(w, r)
	})
}

// RequireAuth пропускает дальше только запросы с валидным access-токеном в
// заголовке Authorization: Bearer <token>, и кладёт id пользователя в контекст.
func RequireAuth(verifier *auth.Verifier) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			header := r.Header.Get("Authorization")
			raw, ok := strings.CutPrefix(header, "Bearer ")
			if !ok || strings.TrimSpace(raw) == "" {
				WriteError(w, r, http.StatusUnauthorized)
				return
			}

			id, err := verifier.UserIDFromToken(strings.TrimSpace(raw))
			if err != nil {
				WriteError(w, r, http.StatusUnauthorized)
				return
			}

			ctx := context.WithValue(r.Context(), userIDKey, id)
			next.ServeHTTP(w, r.WithContext(ctx))
		})
	}
}

// UserIDFrom достаёт id пользователя, положенный RequireAuth.
func UserIDFrom(ctx context.Context) (uuid.UUID, bool) {
	id, ok := ctx.Value(userIDKey).(uuid.UUID)
	return id, ok
}

func LoggerFrom(ctx context.Context) *slog.Logger {
	if logger, ok := ctx.Value(loggerKey).(*slog.Logger); ok {
		return logger
	}
	return slog.Default()
}
```

```go
package web

import (
	"encoding/json"
	"net/http"

	"google.golang.org/grpc/codes"
	"google.golang.org/grpc/status"
)

type errorResponse struct {
	Error string `json:"error"`
}

func WriteJSON(w http.ResponseWriter, status int, v any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	if v != nil {
		_ = json.NewEncoder(w).Encode(v)
	}
}

// WriteError отдаёт единый формат {"error": "..."} с текстом статуса.
// Тексты фиксированные: подробности ошибки наружу не уходят.
func WriteError(w http.ResponseWriter, r *http.Request, status int) {
	if status >= http.StatusInternalServerError {
		LoggerFrom(r.Context()).Error("request failed", "status", status)
	}
	WriteJSON(w, status, errorResponse{Error: http.StatusText(status)})
}

// WriteGRPCError переводит код ответа gRPC в HTTP-статус.
func WriteGRPCError(w http.ResponseWriter, r *http.Request, err error) {
	var httpStatus int

	switch status.Code(err) {
	case codes.NotFound:
		httpStatus = http.StatusNotFound
	case codes.InvalidArgument:
		httpStatus = http.StatusBadRequest
	case codes.AlreadyExists:
		httpStatus = http.StatusConflict
	case codes.Unauthenticated:
		httpStatus = http.StatusUnauthorized
	case codes.PermissionDenied:
		httpStatus = http.StatusForbidden
	case codes.DeadlineExceeded:
		httpStatus = http.StatusGatewayTimeout
	case codes.Unavailable:
		httpStatus = http.StatusServiceUnavailable
	default:
		httpStatus = http.StatusInternalServerError
	}

	if httpStatus >= http.StatusInternalServerError {
		LoggerFrom(r.Context()).Error("upstream grpc call failed", "error", err, "status", httpStatus)
	}
	WriteJSON(w, httpStatus, errorResponse{Error: http.StatusText(httpStatus)})
}
```

```go
package web

import (
	"time"

	userv1 "ahishka/pkg/gen/ahishka/user/v1"
)

// userDTO — форма пользователя наружу. Отдельный тип, а не protojson поверх
// userv1.User: REST-контракт для фронта не должен ездить следом за
// внутренним proto-контрактом.
type userDTO struct {
	ID        string    `json:"id"`
	Name      string    `json:"name"`
	Handle    string    `json:"handle"`
	Bio       string    `json:"bio"`
	City      string    `json:"city"`
	Work      string    `json:"work"`
	Verified  bool      `json:"verified"`
	AvatarURL *string   `json:"avatarUrl"`
	CreatedAt time.Time `json:"createdAt"`
	UpdatedAt time.Time `json:"updatedAt"`
}

func toUserDTO(user *userv1.User) userDTO {
	return userDTO{
		ID:        user.GetId(),
		Name:      user.GetName(),
		Handle:    user.GetHandle(),
		Bio:       user.GetBio(),
```

```go
// Прокси должен донести до auth-service тело и путь без изменений, а обратно
// вернуть статус, тело и Set-Cookie нетронутыми — на cookie держится вся
// сессия, и любая её порча ломает refresh.
func TestAuthProxyPassesRequestAndCookieThrough(t *testing.T) {
	var gotPath, gotBody, gotMethod string

	upstream := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		gotPath = r.URL.Path
		gotMethod = r.Method
		raw, _ := io.ReadAll(r.Body)
		gotBody = string(raw)

		http.SetCookie(w, &http.Cookie{
			Name:     "refresh_token",
			Value:    "opaque-token-value",
			Path:     "/auth",
			HttpOnly: true,
		})
		w.WriteHeader(http.StatusCreated)
		_, _ = w.Write([]byte(`{"access_token":"header.payload.signature"}`))
	}))
	defer upstream.Close()

	proxy, err := NewAuthProxy(upstream.URL)
	if err != nil {
		t.Fatalf("NewAuthProxy: %v", err)
	}

	rec := httptest.NewRecorder()
	req := httptest.NewRequest(http.MethodPost, "/auth/register",
		strings.NewReader(`{"email":"a@example.com","password":"password123"}`))
	proxy.ServeHTTP(rec, req)

	if gotMethod != http.MethodPost {
		t.Errorf("upstream method: got %q, want POST", gotMethod)
	}
	if gotPath != "/auth/register" {
		t.Errorf("upstream path: got %q, want /auth/register", gotPath)
	}
	if !strings.Contains(gotBody, "a@example.com") {
		t.Errorf("upstream body: got %q, want it to carry the email", gotBody)
	}

	if rec.Code != http.StatusCreated {
		t.Errorf("status: got %d, want 201", rec.Code)
	}
	if !strings.Contains(rec.Body.String(), "access_token") {
		t.Errorf("body: got %q, want it to carry access_token", rec.Body.String())
	}

	cookies := rec.Result().Cookies()
	if len(cookies) != 1 || cookies[0].Name != "refresh_token" {
		t.Fatalf("Set-Cookie did not survive proxying: %v", cookies)
	}
	if cookies[0].Value != "opaque-token-value" || !cookies[0].HttpOnly {
		t.Errorf("cookie was altered in transit: %+v", cookies[0])
	}
```

```go
package web

import (
	"net/http/httputil"
	"net/url"
)

// NewAuthProxy проксирует /auth/* в auth-service как есть.
//
// Почему прокси, а не свои хендлеры: auth уже отдаёт REST/JSON и сам ставит
// httpOnly-cookie с нужными Path/SameSite/Secure. Пересобирать ответ в
// gateway значило бы держать логику cookie в двух местах и ломать сессии при
// каждом расхождении.
func NewAuthProxy(target string) (*httputil.ReverseProxy, error) {
	parsed, err := url.Parse(target)
	if err != nil {
		return nil, err
	}
	if parsed.Scheme == "" || parsed.Host == "" {
		return nil, &url.Error{Op: "parse", URL: target, Err: url.ErrMissingProtocolScheme}
	}

	return &httputil.ReverseProxy{
		Rewrite: func(r *httputil.ProxyRequest) {
			r.SetURL(parsed)
			// Путь сохраняем как есть: auth слушает те же /auth/*.
			r.Out.URL.Path = r.In.URL.Path
			r.Out.Host = r.In.Host
			r.SetXForwarded()
		},
	}, nil
}
```

```go
func NewRouter(
	userHandler *UserHandler,
	authProxy *httputil.ReverseProxy,
	verifier *auth.Verifier,
	logger *slog.Logger,
) http.Handler {
	mux := http.NewServeMux()

	// /auth/* уходит в auth-service нетронутым — свои токены он проверяет сам.
	mux.Handle("POST /auth/register", authProxy)
	mux.Handle("POST /auth/login", authProxy)
	mux.Handle("POST /auth/logout", authProxy)
	mux.Handle("POST /auth/refresh", authProxy)

	requireAuth := RequireAuth(verifier)

	mux.Handle("GET /me", requireAuth(http.HandlerFunc(userHandler.Me)))
	mux.Handle("PATCH /me", requireAuth(http.HandlerFunc(userHandler.UpdateMe)))
	mux.Handle("GET /users/{handle}", requireAuth(http.HandlerFunc(userHandler.UserByHandle)))

	mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
		WriteJSON(w, http.StatusOK, map[string]string{"status": "ok"})
	})

	return LoggingMiddleware(logger)(RecoverMiddleware(mux))
```

```go
	"google.golang.org/grpc/credentials/insecure"
)

func main() {
	godotenv.Load()

	app := fx.New(
		fx.Provide(
			config.Load,
			NewLogger,
			NewVerifier,
			NewUserConn,
			NewUserClient,
			NewAuthProxy,
			web.NewUserHandler,
			web.NewRouter,
		),
		fx.WithLogger(func(logger *slog.Logger) fxevent.Logger {
			return &fxevent.SlogLogger{Logger: logger}
		}),
		fx.Invoke(Run),
	)
	app.Run()
}

func NewLogger(cfg *config.Config) *slog.Logger {
	var level slog.Level
	if err := level.UnmarshalText([]byte(cfg.LogLevel)); err != nil {
		level = slog.LevelInfo
	}
	logger := slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{Level: level}))
	slog.SetDefault(logger)
	return logger
}

func NewVerifier(cfg *config.Config) *auth.Verifier {
	return auth.NewVerifier(cfg.JWTSecret)
}

// NewUserConn держит соединение с user-service. grpc.NewClient не ходит в сеть
// при создании — соединение поднимается лениво, поэтому недоступный
// user-service не роняет старт gateway (в отличие от NATS у user-service).
func NewUserConn(lc fx.Lifecycle, cfg *config.Config, logger *slog.Logger) (*grpc.ClientConn, error) {
	conn, err := grpc.NewClient(cfg.UserServiceAddr,
		grpc.WithTransportCredentials(insecure.NewCredentials()))
	if err != nil {
		return nil, err
	}

	lc.Append(fx.Hook{
		OnStop: func(ctx context.Context) error {
			logger.Info("closing user-service connection")
			return conn.Close()
		},
	})
	return conn, nil
}

func NewUserClient(conn *grpc.ClientConn) userv1.UserServiceClient {
	return userv1.NewUserServiceClient(conn)
}

func NewAuthProxy(cfg *config.Config) (*httputil.ReverseProxy, error) {
	return web.NewAuthProxy(cfg.AuthServiceURL)
}

func Run(lc fx.Lifecycle, router http.Handler, cfg *config.Config, logger *slog.Logger, shutdowner fx.Shutdowner) {
	srv := &http.Server{
		Addr:    ":" + cfg.HTTPPort,
		Handler: router,
	}

	lc.Append(fx.Hook{
		OnStart: func(ctx context.Context) error {
			logger.Info("starting http server", "addr", srv.Addr)
			go func() {
				if err := srv.ListenAndServe(); err != nil && err != http.ErrServerClosed {
					logger.Error("http server failed", "error", err)
					_ = shutdowner.Shutdown()
				}
			}()
			return nil
		},
		OnStop: func(ctx context.Context) error {
			logger.Info("stopping http server")
			return srv.Shutdown(ctx)
		},
	})
}
```

Обрати внимание на `insecure.NewCredentials()`: gateway и user-service общаются внутри докер-сети без TLS. Это осознанно для текущего этапа; mTLS между сервисами — отдельная задача, не решается здесь.

## Что НЕ входит в этот план

- **Маршруты будущих сервисов** (`/feed`, `/posts`, `/groups`, `/conversations`, `/notifications`, `/search`) — появятся вместе со своими сервисами. `search` по замыслу будет агрегатором прямо в gateway.
- **`X-User-Id` / gRPC-metadata:** сейчас `id` едет в теле gRPC-сообщения, потому что нынешний контракт user-service принимает его явным полем. Metadata понадобится, когда сервису нужно будет знать «кто спрашивает» отдельно от «про кого спрашивают» — например post-service, где автор поста это вызывающий.
- **CORS** — фронт пока не ходит в gateway из браузера; появится вместе с `frontend/`.
- **Rate limiting, mTLS между сервисами, RS256 + JWKS** — по roadmap RS256 идёт после HS256, остальное не начато.
- **Health-check у user-service** (`grpc_health_v1`) и, соответственно, `condition: service_healthy` в `depends_on` у gateway — сейчас `service_started`, потому что проверять нечем.
- **Автопрогон миграций** — обе БД по-прежнему накатываются вручную через goose.
